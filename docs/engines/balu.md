# Engine `pine.balu_zone` (v1, ready): port of `Balu_Zone_Scalper_v2.pine` L74–895

Code `backend/src/nifty/engines/balu/` (one module per Pine section; the 15-step bar order is `steps.py`). Port maps: `docs/pine/BALU-1..3.md`. Default timeframe 5m, intraday only, tick size from the instrument.

**Params** (`BaluParams`): every Pine input at its default and bounds, snake_case. `ui` (not in `config_hash`): zone/label/gold/CVD/panel toggles, tint, panel position, colours. Gating toggles stay params (`show_div`, `show_footprint`, `fp_mark_traps`, `fp_at_zone_only`, `sweep_conf_only`, `use_prob`, `show_key_levels`, `kl_*`, `use_htf_levels`). Port-only: `ema_seed` (`first`|`sma`), `pivot_ties` (`default`|`strict`), `proxy_volume_instrument` (front-month future, used only with `gold_proxy`).

**Outputs.** Plots: `atr golden gold_val gold_state regime_idx cvd moving_line moving_line_raw flow_z flow_state flow_ready day_len or_high or_low pool_size zones_size next_up next_dn next_up_proj next_dn_proj loc_idx tap_demand_bot tap_supply_top zones_up zones_dn fp_n fp_tot fp_imb fp_valid press_buy press_sell sweep_d_conf sweep_s_conf state_id n_up n_dn n_timeout n_both n_cut n_pending sample_days`. Overlays: zones `z<seq>` (versioned: active/projected/mitigated/deleted), key-level rails `kl:<NAME>:<date>`, markers `pb:` `ps:` (pressure) and `swd:` `sws:` (sweeps, on the confirming bar). Events: `divergence {side, pivot_bar_start, known_bar_start}`; `alert {kind, name, zone_center?, imb?}` with kind `regime_bull regime_bear divergence_bear divergence_bull press_buy press_sell sweep_demand sweep_supply`, plus provisional `press_buy_early press_sell_early` from `on_provisional` (reads state, never writes it). `panel()` = the 13 Pine rows for the latest confirmed bar. `warmup_bars = 105`.

**Snapshot.** `{"v": 1, "slots": {...}}`, JSON-safe (NaN as null): session state and ATR, level pool, swing/HTF pivots, golden and flow windows, zones with their id counter, key-level rails, pressure average, sweep machines and done lists, path-history arrays and the open episode, previous regime, panel values. Restart property: batch == incremental == restart on the oracle (random cuts, JSON round trip).

**Limits.** Pressure needs 1m sub-bars (`fp_ltf` in 1/3/5/10/15/30/60 minutes, strictly below the chart and dividing it, else suppressed / `ConfigError`). Prior-day and HTF values come from the supplied dataset (the first session has no prior day; Auto HTF for 5m is 30m). Index data has no volume: the golden line is a TWAP and delta/effort use the bar range, which is a proxy, not order flow. Proxy volume needs a front-month future. EARLY alerts are live only (TradingView exports have none). Path-history counts depend on the history length supplied and are descriptive, not a forecast ("Not established", D18). Marker shapes (circle, ×) are carried in `style` but the web draws role arrows.

**Check.** `make test T=backend/tests/unit/engines/balu`; `make parity E=pine.balu_zone` compares the `dbg_*` plots with `fixtures/tv_golden/balu/ohlc_plots.csv` (Tier A) once you export it (`fixtures/tv_golden/BALU_DEBUG_PLOTS.pine.txt`, RUNBOOK §Golden). Speed: `make bench` (about 5,500 chart bars/s batch).
