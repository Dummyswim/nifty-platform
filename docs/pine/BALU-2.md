# BALU-2 port map: `reference/pine/Balu_Zone_Scalper_v2.pine` L431–769 (zone map, key levels, location, intrabar pressure, sweeps)

Pine is authoritative: if this map disagrees, follow Pine and log in STATE. Chunk C10 reads Pine **L431–769 only** and builds on BALU-1's `LevelPool` (`f_nearestAbove/Below`), `SessionState` (`dayLen`, `orBars`, `orHigh/orLow`, `isNewSession`), `atr`, `sPH/sPL`. Parameter names and defaults are in BALU-1.

## Aux data (runner-supplied through `EngineContext`, see `docs/spec/04-pine-parity.md`)
`ctx.sub_bars(bar, res)` returns the finalized `res` bars (default 1m) whose start lies in `[bar_start, bar_end)`; in `on_provisional` it also includes the partial current one. `fpLtf` other than "1" is built from the 1m store by the D08 resample and must divide the chart timeframe, else `ConfigError`.

## Zones (L433–566)
State: ordered list `zones` (**creation order matters**: location loops overwrite by array order). `Zone{id, top, bot, center, is_demand, is_projected, mitigated, created_bar_start}`. `f_makeZone` L454: `half = max(atr*zoneThickATR, 4*mintick)`, `top=center+half`, `bot=center−half`; appended at the end. Overlay: `kind=zone`, `id="z<seq>"`, `t0=created bar start`, `t1=null`, role `demand|supply`, `meta{status active|mitigated|projected, tier=k+1 (display only), top, bot, center}`, text "Demand"/"Supply" (+" (proj)"). Mitigation = new `ver` with `status=mitigated`, `t1=this bar end`; drop = `deleted=true`. `showZones/showZoneLbl` are `ui`.

Each **confirmed** bar, in this order:
1. **Housekeeping** L470–490, only if `zones` non-empty and `atr` valid. `structureChanged = sPH or sPL valid` L469 (chart-TF pivots only). `far = atr*pruneATR`. For `i` from last to first: if not mitigated and (demand: `close < bot` | supply: `close > top`) ⇒ `mitigated=true`. Then `stale = projected and not mitigated and structureChanged`. Drop the zone if `stale or (mitigated and not keepMitigated) or |center−close| > far`.
2. **Rebuild** L493–566, only if `atr` valid and in session. `gap = max(atr*zoneThickATR*2, 0.25*atr)` L494; `space = max(gap, atr*minSpaceATR)` L496.
   - Scan zones in order, live ones only (not mitigated): demand centers → `spaceDn`, supply centers → `spaceUp` (every live zone, including one price is inside). Supply with `bot > close`: `haveUp += 1`, push center to `usedUp`. Demand with `top < close`: `haveDn += 1`, push to `usedDn`.
   - **v2.1 far-zone replacement** (L520 up / L532 down; at most once per side per bar). Up: if `haveUp ≥ zoneTiers`: `cand = nearestAbove(close, gap, spaceUp, space)`, `farUp = max(usedUp)`; if `cand` valid and `cand < farUp` and `farUp − close > atr*(capBaseATR + capStepATR*(haveUp−1))`: delete the live supply zone with `center == farUp` (search from the end, first hit), remove `farUp` from `usedUp` and `spaceUp` (first occurrence), `haveUp −= 1`. Down mirrors (`min(usedDn)`, `nearestBelow`, `cand > farDn`, `close − farDn > …`).
   - **Fill** L544 up / L557 down: for `k = haveUp .. zoneTiers−1`: `cap = atr*(capBaseATR + capStepATR*k)`; `cand = nearestAbove(close, gap, spaceUp, space)`; `proj = cand is NaN or cand−close > cap`; `lvl = proj ? close+cap : cand`; if `proj and spaceUp` non-empty: `lvl = max(lvl, max(spaceUp)+space)`; if `not proj or lvl ≤ close+cap`: make zone at `lvl` (supply, projected=proj), push `lvl` to `usedUp` and `spaceUp` (the next `k` sees it). `k` advances even when a tier is omitted. Down: `lvl = proj ? close−cap : cand`; `lvl = min(lvl, min(spaceDn)−space)`; condition `lvl ≥ close−cap`; demand zone.
   - Rebuild runs every confirmed bar, not only on new structure.

## Key levels (L577–625)
Day-scoped rails: on `isNewSession` (if `showKeyLevels`) delete all previous rails, then create (skipping NaN prices): PDH and PDL (solid), PDC (dotted) per `klPDHL/klPDC`; PP, R1, S1 (dashed) if `klPivot` (L604–615). At `dayLen == orBars` on a confirmed in-session bar (`klOR`): ORH, ORL (dashed) L617–619 (same bar as the clear when `orBars == 1`, after it). Overlay: `kind=hline`, `t0=bar_start`, `t1=null`, `style{role=info, dash}`, `text=name`; the clear = `deleted=true` ops at the new session's first bar.

## Location (L626–663; every bar, after the zone steps of the same bar)
`prox = atr*zoneProxATR` L629. For each non-mitigated zone in array order: if `z.bot−prox ≤ close ≤ z.top+prox`: demand ⇒ `atDemand=true, tapDemandBot=z.bot, tapDemandC=z.center`; supply ⇒ `atSupply=true, tapSupplyTop=z.top, tapSupplyC=z.center` (later zones overwrite). Supply with `bot > close` and (`nextUp` NaN or `bot < nextUp`) ⇒ `nextUp=bot, nextUpProjected=z.isProjected`; demand with `top < close` and (`nextDn` NaN or `top > nextDn`) ⇒ `nextDn=top`, flag likewise. `locIdx = atDemand ? 0 : atSupply ? 2 : 1` L660 (demand wins), text AT DEMAND / AT SUPPLY / MID.

## Intrabar pressure (L664–700)
Per 1m sub-bar `i`: `effort_i = vol>0 ? vol : (high−low)`; `signed_i = ((high−low)>0 ? (2*close−high−low)/(high−low) : 0) * effort_i` (L673–674). `fpTot = Σ nz(effort_i)`, `fpNet = Σ nz(signed_i)`, `fpN = count` (0 when none). `fpValid = showFootprint and fpLtf_seconds < chart_seconds and fpN ≥ fpMinSubBars and fpTot > 0` L687 (suppressed on a 1m chart). `fpAvg = sma(fpTot, fpEffLen)` over **chart bars of the whole history** (NaN until full); `fpImbNow = fpTot>0 ? fpNet/fpTot : 0`; `fpBig = fpValid and (fpAvg is NaN or fpTot ≥ fpAvg*fpEffMult)`. `pressBuy = fpBig and fpImbNow ≥ fpImbal and (not fpAtZoneOnly or atDemand)`; `pressSell = fpBig and fpImbNow ≤ −fpImbal and (not fpAtZoneOnly or atSupply)`. Index data has no volume ⇒ effort is range.

## Sweeps (L696–755)
`fpUpWick = (high − max(open,close))/rangeBar`, `fpDnWick = (min(open,close) − low)/rangeBar`. `sweepDemand = tapDemandBot valid and low < tapDemandBot and close > tapDemandBot and fpDnWick ≥ 0.2`; `sweepSupply = tapSupplyTop valid and high > tapSupplyTop and close < tapSupplyTop and fpUpWick ≥ 0.2` (L698–699).
Per side state `(C, Bot|Top, X, Bar)` plus `done` list; reset on `isNewSession` (`Bar=NaN`, `done` cleared). Per bar in this order (demand; supply mirrors with `high/low` swapped and `close > Top` cancel, `close < X` confirm): (a) if `Bar` set: if `close < Bot or bar_index − Bar > sweepConfBars` ⇒ cancel; else if `close > X` ⇒ `confirmed=true`, push `C` to `done`, clear. (b) then if `sweepDemand and Bar is clear and atr valid and farFromAll(done, tapDemandC, 0.7*atr)` (`|d−C| > 0.7*atr` for every done center): arm with `C=tapDemandC, Bot=tapDemandBot, X=high (of this bar), Bar=bar_index` (L744/L749). So the sweep bar itself is never evaluated, the confirm window is bars +1..+`sweepConfBars`, and a bar that cancels may arm again. `markSweepD = sweepConfOnly ? confirmed : sweepDemand`. The machine runs even when `showFootprint` is off; only marks and alerts need `showFootprint and fpMarkTraps`.

## Outputs
Plots (0/1 as floats): `next_up, next_dn, next_up_proj, next_dn_proj, loc_idx, tap_demand_bot, tap_supply_top, zones_up, zones_dn, fp_n, fp_tot, fp_imb, fp_valid, press_buy, press_sell, sweep_d_conf, sweep_s_conf`. Overlays: zones, key-level rails, markers (`circle` below bar for pressBuy, above for pressSell; `xcross` on the **confirming** bar for sweeps). Events (`alert`, confirmed, at bar close): `press_buy`, `press_sell`, `sweep_demand`, `sweep_supply` (L763–768) with `{zone_center, imb}`. `on_provisional(bar)` computes the pressure on the partial sub-bars with the last confirmed zones and emits **provisional** `press_buy_early` / `press_sell_early` (L765–766); it must not touch zones, sweeps or path state (tested). TradingView exports contain no EARLY alerts, so no parity for them.
