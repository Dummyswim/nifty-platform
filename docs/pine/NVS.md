## Params (defaults; verify against L46–110)
EMA 9/21 · `useRsi` true, RSI 14, long ≥ 60 / short ≤ 40, fresh-cross window 3 bars · ATR 14 · `minDevAtr` 0.25, `maxDevAtr` 1.6, `speedBars` 3, `minSpeedAtr` 0.35, `closePosMin` 0.6, `chopBars` 20, `maxVwapFlips` 3 · `minRiskAtr` 0.7, `maxRiskAtr` 1.8, `targetR` 1.5, `beR` 1.0, `beOffsetR` 0.05, `maxHoldBars` 15 · `exitVwapBufAtr` 0.1, `extAtr` 2.0, `rsiExit` 50 · `costBps` 2.5, `minTgtCostX` 2.5 · entries 930–1445 and flat 1515 (HHMM ints → `toMin`; compared with the bar END in IST) · `warmupBars` 30, `minSessBars` 5, `cooldownBars` 2, `maxTradesDay` 6, `maxDayLossR` 3.0 · `allowLong/allowShort` true.
Port-only params: `anchor_mode` = `signal_close` (Pine, default) | `fill_price` (the Python twin); `ema_seed` = `first` | `sma`.

## Per-bar order (the runner calls `broker.process_bar(bar)` first, then `on_bar(bar)` at the bar close)
1. `dirStart = dir`. Clock: `inSess` = bar START in 09:15–15:30 IST; `endMin` = IST minutes of the bar END; `newSess = inSess and (isfirst or timeframe.change("D") or not inSess[1])`.
2. Indicators: `trSess = (newSess or na(close[1])) ? high−low : max(high−low, |high−close[1]|, |low−close[1]|)`; `atr = rma(trSess, atrLen)`; `rsi`, `emaF`, `emaS`. Session VWAP of hlc3, reset on `newSess` (also `prevSide=0`, `nSess=0`): `v=nz(volume)`; `cumTP += hlc3`; if `v>0` add to `cumPV/cumV`; `vwap = cumV>0 ? cumPV/cumV : cumTP/max(nSess,1)` (index ⇒ TWAP).
3. Spread: `dev=close−vwap`, `devAtr=dev/atr`, `speed = nSess>speedBars ? devAtr−devAtr[speedBars] : na`. `side=sign(dev)`; `flipAt = (inSess and side≠0 and prevSide≠0 and side≠prevSide)`; then update `prevSide` (only when `inSess and side≠0`); `flips = Σ nz(flipAt[i])` for `i=0..max(0, min(chopBars−2, nSess−1))`. `rsiWasBelow/Above` = any `rsi[i] < rsiLong` / `> rsiShort` for `i=1..rsiCrossBars`. `loc = (close−low)/(high−low)`, 0.5 if range 0.
4. Closed-trade accounting: `sinceExit = min(sinceExit+1, 1000)`; for each trade newly closed: `net=(xp−ep)*sgn − ep*costBps/1e4`, `r = curRisk>0 ? net/curRisk : 0`, `rToday += r`; after the loop `sinceExit=0`. Trades closed by the emulator during bar t are visible at t; those closed with `immediately=true` at t+1.
5. On `newSess`: `tradesToday=0`, `rToday=0` (after step 4, so an EOD trade's R is added then discarded).
6. Bookkeeping: `inPos = position_size≠0`. If `waitFill`: clear it; if `inPos` then `holdBars=0, mfe=0, beOn=false`, else `dir=0` (stopped inside the fill bar, or never filled). Else if not `inPos`: `dir=0`. If `newSess and inPos`: `close_all("SESSION_END", immediately)` (`inPos` stays stale for the rest of this bar: replicate).
7. Exits, only if `inPos and dir≠0`: `holdBars += 1`; `mfe = max(mfe, long ? high−entryPx : entryPx−low)`; if `not beOn and mfe ≥ beR*curRisk`: `beOn=true`, `lvl = entryPx + dir*(entryPx*costBps/1e4 + beOffsetR*curRisk)`, `curStop = long ? max(curStop, lvl) : min(curStop, lvl)`. Reason priority: `EOD` (`endMin ≥ flatMin or last bar of session`) > `VWAP_LOSS` (`(close−vwap)*dir < −exitVwapBufAtr*atr`) > `STRETCH_STALL` (`devAtr*dir ≥ extAtr and (close−close[1])*dir < 0`) > `RSI_FADE` (`useRsi` and long `rsi<rsiExit` / short `rsi>rsiExit`) > `TIME` (`holdBars ≥ maxHoldBars`). If a reason: `EOD` ⇒ `close(id, immediately)` and `dir=0`; others ⇒ `close(id)` (fills at the next open, exit comment = reason). Else re-issue `exit("X", id, stop=curStop, limit=curTP)` with comments `BE_STOP|SL` (loss) and `TP` (profit). A BE ratchet takes effect from the next bar.
8. Entry: `ready = inSess and not na(atr, devAtr, speed, rsi if useRsi) and bar_index+1 ≥ warmupBars and nSess ≥ minSessBars and endMin ∈ [entryStartMin, entryEndMin] and sinceExit ≥ cooldownBars and tradesToday < maxTradesDay and rToday > −maxDayLossR and flips ≤ maxVwapFlips`.
   `longOk = close>vwap and emaF>emaS and (not useRsi or (rsi ≥ rsiLong and rsiWasBelow)) and minDevAtr ≤ devAtr ≤ maxDevAtr and speed ≥ minSpeedAtr and close>open and loc ≥ closePosMin`; `shortOk` mirrored (`devAtr ∈ [−max, −min]`, `speed ≤ −minSpeedAtr`, `close<open`, `loc ≤ 1−closePosMin`, `rsi ≤ rsiShort and rsiWasAbove`).
   Only if `ready and not inPos and not waitFill and dir==0`: `sigDir = longOk and allowLong ? 1 : shortOk and allowShort ? −1 : 0`. Then `rawRisk = long ? close−low : high−close`; `risk = max(rawRisk, minRiskAtr*atr)`; accept if `rawRisk ≤ maxRiskAtr*atr and targetR*risk ≥ minTgtCostX*close*costBps/1e4`. On accept: `dir=sigDir`, `waitFill=true`, `curRisk=risk`, `curStop = round_to_mintick(close − sigDir*risk)`, `curTP = round_to_mintick(close + sigDir*targetR*risk)` (anchored to the SIGNAL-bar close), `tradesToday += 1` (at signal time, even if never filled); `entry("BUY"|"SELL")` and `exit("X", stop, limit)` are both sent now (the bracket can trigger on the fill bar).
   Event payload `why`: `RSI <n> crossed <level> | VWAP|TWAP spread <x> ATR (<pts> pts) | speed <s> ATR/<speedBars> bars | EMA<f>><s>`.

## Outputs
Plots (L320–335): `vwap` (NaN outside the session), `ema_fast`, `ema_slow`, `buy_near/buy_far = vwap ± minDevAtr/maxDevAtr*atr`, `sell_near/sell_far`, `stop`, `target` (step lines, only while `dirStart≠0 or dir≠0`). Events: entry (BUY/SELL, SL, TP, why), exit (reason + R). Panel (L336–358, 8 rows): title (VWAP|TWAP), Spread, Speed, RSI, Bias (BULL|BEAR|MIXED), VWAP flips `n / max` (+CHOP), Today `trades, R`, Position.
Exit reasons recorded: `TP, SL, BE_STOP, VWAP_LOSS, STRETCH_STALL, RSI_FADE, TIME, EOD, SESSION_END`.

## Oracle (`reference/oracle/`) and known twin differences
`vwap_scalper.py` enters at the next open and re-anchors stop/target to the actual fill (skips on a gap), resolves same-bar hits stop-first, seeds EMA with the first close, gives RSI 50 when both averages are 0, counts flips differently. Ignore its Dhan/Yahoo/live code. `VWAP_SCALPER.md`: PineTS on the 5m-resampled `nifty_1m.csv` produced the same 15 entries (time + price) and 14/15 exits (bar + reason) as the twin; `logs/scalper_trades.csv` holds those 15 trades. Regenerate: `python reference/oracle/vwap_scalper.py backtest --csv reference/oracle/data/nifty_1m.csv --minutes 5` (read its `--help` first).
